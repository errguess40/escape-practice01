# escape-practice01

ブラウザで遊べる脱出ゲームの習作です。\
HTML / CSS / JavaScript だけで作っています。

**▶ 遊ぶ:** https://errguess40.github.io/escape-practice01/

## あらすじ

目が覚めると、知らない部屋にいた。
1Kのアパートの部屋を調べて謎を解き、玄関の扉から外に出よう。

## ゲームの概要

- プレイ時間: 15分前後
- 対応環境: 最新版の Chrome / Edge / Safari / Firefox(PC・スマホの両方)
- 音: なし

## 遊び方

| 操作 | 方法 |
|---|---|
| 向きを変える | 画面の左右にある矢印を押す |
| 調べる | 部屋の物をタップ(クリック)する |
| アイテムを使う | 持ち物欄でアイテムを選び、使いたい物をタップする |
| やり直す | 左上のメニューから「最初から」を選ぶ |

- 進み具合は自動で保存されます。ブラウザを閉じても、次に開いたときに続きから遊べます。
- 保存データは、遊んでいるブラウザの中(localStorage)にだけ残ります。

## 注意

URL の末尾に `?debug=1` を付けると、デバッグパネルが表示されます。\
好きな場面へ直接移動したり、保存データを消したりできます(通常のプレイでは表示されません)。
