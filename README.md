# escape-practice01

ブラウザで遊べる脱出ゲームの習作です。\
`index.html` 1ファイルで動き、3Dの描画には [three.js](https://threejs.org/) を使っています。

**▶ 遊ぶ:** https://errguess40.github.io/escape-practice01/

## あらすじ

目が覚めると、知らない部屋にいた。\
部屋を調べて謎を解き、玄関の扉から外に出よう。

## ゲームの概要

- プレイ時間: 20分前後
- 対応環境: 最新版の Chrome / Edge / Safari / Firefox(PC・スマホの両方)
- 通信:three.jsをCDNから読み込むため、インターネット接続が必要です
- 音: なし
- 言語: 日本語 / 英語

## 遊び方

| 操作 | 方法 |
| --- | --- |
| 向きを変える | 部屋の下にある左右の矢印を押す |
| 調べる | 部屋の物をタップ(クリック)する |
| 近くで見た状態から戻る | 部屋の下、中央にある下向きの矢印を押す |
| アイテムを使う | 持ち物欄でアイテムを選び、使いたい物をタップする |
| 言語を切り替える | タイトル画面の「日本語」「English」ボタンを押す |
| やり直す | 右下のメニューから「タイトルに戻る」を選び、「最初から始める」を押す |

- 進み具合は自動で保存されます。ブラウザを閉じても、タイトル画面の「続きから始める」で続きから遊べます。
- 保存データは、遊んでいるブラウザの中(localStorage)にだけ残ります。
- 選んだ言語も保存され、次に開いたときはその言語で始まります(最初は日本語)。
- 一部の謎の答えは、最初から始めるたびに変わります
